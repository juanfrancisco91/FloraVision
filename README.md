# FloraVision 🌹

Sistema inteligente para identificación y clasificación de flores mediante inteligencia artificial.

## Tecnologías utilizadas

- Python
- Streamlit
- Inteligencia Artificial
- Git/GitHub

## Instalación

Clonar repositorio:

```bash
git clone https://github.com/juanfrancisco91/FloraVision.git
```

Entrar al proyecto:

```bash
cd FloraVision
```

Crear entorno virtual:

```bash
python -m venv .venv
```

Activar entorno:

```bash
.venv\Scripts\activate
```

Instalar dependencias:

```bash
pip install -r requirements.txt
```

Ejecutar aplicación:

```bash
streamlit run floravision.py
```
